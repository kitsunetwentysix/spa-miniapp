# Spa-вечер: Telegram Mini App

Мини-приложение в Telegram: девушка выбирает процедуры домашнего spa-вечера, приложение собирает программу по времени, бот присылает её выбор мне.

**Стек:** HTML/CSS/JS + Telegram WebApp API (фронт на GitHub Pages), Python + aiogram 3 (бот).

## Как это работает

1. Она пишет боту `/start`, бот показывает кнопку «Выбрать процедуры».
2. Кнопка открывает Mini App (`index.html`). Она отмечает процедуры, аромат, время и пожелания.
3. «Записаться» строит расписание вечера, «Да, всё верно» передаёт заказ боту через `Telegram.WebApp.sendData`.
4. Бот (`bot.py`) получает данные и пересылает программу владельцу.

## Запуск

### 1. Бот
В @BotFather: `/newbot`, затем сохрани токен.

### 2. Страница на GitHub Pages
1. Создай публичный репозиторий `spa-miniapp` и загрузи туда файлы проекта (`.env` не загружается, он в `.gitignore`).
2. Settings → Pages → Source: `Deploy from a branch`, ветка `main`, папка `/ (root)`.
3. Через минуту страница будет доступна по адресу `https://<логин>.github.io/spa-miniapp/`.

### 3. Настройки
Скопируй `.env.example` в `.env`, вставь `BOT_TOKEN` и `WEBAPP_URL`.

### 4. Запуск бота
```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python bot.py
```
Напиши боту `/id`, вставь число в `.env` как `OWNER_ID` и перезапусти бота.

### 5. Проверка
Сам нажми `/start` → «Выбрать процедуры» → «Записаться» → «Да, всё верно». Бот ответит «Записала тебя…» и пришлёт полный заказ владельцу. Потом отправь ссылку на бота ей.

## Важно
- Бот работает, пока запущен `python bot.py`. На вечер хватит компьютера.
- `sendData` работает только из кнопки под полем ввода, а не из Menu Button. Поэтому кнопка выдаётся командой `/start`.
- Владелец должен хотя бы раз написать боту `/start`, иначе Telegram не даст боту прислать ему сообщение.

## База заказов

Каждый заказ сохраняется в SQLite (`orders.db` рядом с ботом, модуль `db.py`) до отправки сообщений, поэтому не теряется, даже если Telegram не ответил.

Команды владельца (работают только с `OWNER_ID`):

| Команда | Что делает |
|---|---|
| `/orders` | Последние 10 заказов списком |
| `/order 5` | Полный текст заказа №5 |
| `/export` | Все заказы файлом CSV для Excel / Google Таблиц |
